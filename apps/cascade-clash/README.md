# Cascade Clash

CPU対戦型・落ちもの連鎖パズルゲーム。ブラウザだけで遊べる、完全オリジナル作品です。

**Cascade Clash** は本プロジェクト独自の英語名称であり、既存の商用パズルゲームのタイトル・キャラクター名・固有デザインは一切使用していません。ピースや盤面の見た目はすべて Canvas 2D の図形描画、効果音はすべて Web Audio API による波形合成で、画像ファイル・録音音源ファイルは1つも使っていません。外部API・課金APIも一切不使用です（$0運用）。

> **2026-07-11 ユーザーフィードバックにより v1.1 改訂**: 分離落下・通式スコア・相殺・予告アイコン・大型レイアウトとゼリー演出を追加しました。詳細はリポジトリルートの `README.md` を参照してください。

## 概要

プレイヤーと CPU がそれぞれ 6列×12行の大型盤面を持ち、同時に対戦します。2セル1組のピースを操作し、ロック時には各セルが独立に自列へ着地（分離落下）します。同色4個以上を隣接させて消去（カスケード）すると、通(Tsu)式のレバレッジ攻撃システム（連鎖パワー×色ボーナス×グループボーナス）でスコアが加算され、攻撃ポイントに応じて相手盤面へ「ブロッカー」を送り込めます。送信予定のブロッカーは相手からの送信待ちブロッカーと相殺されます。相手の盤面を先に埋めた側の勝ちです。

## 遊び方

1. タイトル画面から「ゲーム開始」を選択
2. CPUの難易度（初級/中級/上級）を選択
3. ピースを操作して同色4個以上を消去し、連鎖を狙う
4. 相手より先に盤面を埋められたら負け、埋めた側が勝ち

ゲーム内の「操作説明」画面からいつでも操作方法を確認できます。

## スコア・ブロッカーシステム（概要）

- **スコア**: 段スコア = (10×消去数) × clamp(連鎖パワー + 色ボーナス + グループボーナス, 1, 999)。連鎖パワーは `[0,8,16,32,64,96,128,160,...]` のレバレッジ曲線です。
- **ブロッカー送信**: 攻撃ポイント（スコア+繰り越し）÷70 が送信数（端数は繰り越し）。1回の投下で降下する数は最大30個。
- **相殺**: 自分の新規攻撃ポイントは、まず相手からの送信待ちブロッカーとの相殺に充当されます。
- **予告アイコン**: 待機中のブロッカー数を5段階（小雫/カプセル/クリスタル/スター/ムーン）のアイコンで表示します。

詳細な数値仕様はリポジトリルートの `README.md` および `SPEC.md` を参照してください。

## 操作方法

### キーボード

| 操作 | キー |
|---|---|
| 左移動 | `←` |
| 右移動 | `→` |
| 時計回り回転 | `X` または `↑` |
| 反時計回り回転 | `Z` |
| ソフトドロップ | `↓`（押下中） |
| 一時停止 | `P` |

### タッチ

画面下部の左移動/右移動/回転(CW)/回転(CCW)/ソフトドロップの各ボタン、またはスワイプジェスチャーで操作できます。一時停止ボタンは画面上部に常時表示されます。

## ビジュアル・演出

大型プレイフィールド、ゼリー質感のプロシージャル描画（squash&stretch）、連鎖段数に応じたエスカレーション演出、攻撃光弾、相殺スパーク、オーロラ背景を採用しています。`assets/sprites/` にBlender生成PNG（23枚）を配置すると、プロシージャル描画から自動的に3Dスプライトへ切り替わります（生成コマンドはリポジトリルートの `README.md` を参照）。

## 技術構成

- Vanilla TypeScript（strict mode）+ Canvas 2D API + Web Audio API
- 実行時依存ゼロ、外部API・外部CDN・外部フォント不使用
- レスポンシブ対応（デスクトップ/モバイル）、キーボード/タッチ/スワイプ操作対応
- アクセシビリティ配慮（フォーカス可視化、コントラスト確保、色以外の識別補助）

詳細な技術仕様・アーキテクチャ・CPUアルゴリズムの解説は、リポジトリルートの `README.md` を参照してください。
