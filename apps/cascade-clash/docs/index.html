はじめに

このゲームについて

Cascade Clash（カスケード・クラッシュ）は、ブラウザで遊べる CPU対戦型の落ちもの連鎖パズルゲームです。6列×12行の盤面に2セル1組のピースを積み、同色4個以上を隣接させて消すと連鎖（カスケード）が発生します。連鎖で得たスコアに応じて、相手の盤面に「ブロッカー」と呼ばれる邪魔ブロックを送り込み、先に盤面が埋まった方が負けです。

🎯 目的

プレイヤー vs CPU の1対1対戦で、連鎖を組んで相手を先に詰ませる

✨ 特長

外部音源・外部通信なしのVanilla TypeScript実装。CPUは初級/中級/上級の3段階で強さが変わる
📖 このサイトは 仕様書（ルール・CPU・技術構成）と 操作手順書（キーボード/タッチ）の構成です。左メニューから各ページへ移動できます。音声ナレーションは課金APIのGoogle Cloud TTSを使用する方針のため、本バージョンでは無効化しています（テキストのみで完結する内容です）。
仕様書

ルール（連鎖・スコア・ブロッカー）

分離落下

ピースは2セル1組で操作しますが、ロックされる瞬間に上下2セルの連結は解除され、各セルが独立に自列の最下段へ着地します。片方のセルの下だけが空いている場合、そのセルだけが先に落ちきることがあります。

連鎖（カスケード）の仕組み

上下左右に隣接する同色セルが4個以上つながると消去されます。消去後は空いた場所に上のセルが重力で落下し、その結果また4個以上つながればさらに連鎖（カスケード）が発生します。これが止まるまで自動的に繰り返されます（安全弁として最大20回で強制終了）。

スコア計算（通式レバレッジ攻撃システム）

2026-07-11のユーザーフィードバックにより、通(Tsu)式のレバレッジ攻撃システムに改訂されました（リサーチ出典: Puyo Nexus Wiki の Scoring / Nuisance queue。数値は本プロジェクト独自定義です）。

段スコア = (10 × その段の消去数) × clamp(連鎖パワー + 色ボーナス + グループボーナス, 1, 999)
段数12345678
連鎖パワー0816326496128160

6段目以降は直前の段から+32ずつ増加します。色ボーナスは同一段で消えた色の種類数（1色=0、2色=3、3色=6、4色=12）、グループボーナスは1グループの消去セル数に応じたボーナス（4個=0〜11個以上=10）を全グループ分合算した値です。

ブロッカー（おじゃま）の送信・相殺

1回のピース設置で発生した全カスケード段のスコア合計に前回の繰り越しを加えた「攻撃ポイント」を70で割った数（切り捨て、端数は次回へ繰り越し）が送信ブロッカー数になります。相手盤面へ1回の投下で実際に降下する数は最大30個で、超過分はキューに残り次回に持ち越されます。自分の新規攻撃ポイントは、まず相手からの送信待ちブロッカーとの相殺に充当され、相殺しきれない分だけが新たに相手へ送られます。ブロッカーは消去はできますが自分では消せない無色のセルで、隣接する色が消えるときに巻き込まれて一緒に消えることはあります。

予告おじゃまアイコン

待機中のブロッカー数は、5段階のオリジナルアイコン（tier1=小雫1個 / tier2=カプセル6個 / tier3=クリスタル30個 / tier4=スター90個 / tier5=ムーン180個）で可視化されます。

盤面の上から3行目にセルが積み上がると「危険状態」として警告表示されます。隠し行（最上部）まで新しいピースが置けなくなった時点でそのプレイヤーの敗北です。

CPUアルゴリズム

対戦相手のCPUは、現在のピースについて列×回転姿勢の組み合わせ（最大24通り、実質22通り前後）を仮想的にシミュレーションし、それぞれを評価関数でスコアリングして最良の一手を選びます。

評価関数

評価値 = 消去数スコア(+) + 連鎖予測スコア(+)
        − 高さペナルティ(−) − 凹凸ペナルティ(−) − 危険度ペナルティ(−)

消去数が多く、将来の連鎖につながりやすく、盤面が低く平らで、危険ラインを超えていない手ほど高く評価されます。

CPUの思考は1フレームあたり最大6候補ずつ評価する「タイムスライス」方式で行われ、画面のカクつきなく非同期にじっくり考えます。プレイヤーの操作や描画をブロックすることはありません。

技術構成とテスト

技術スタック

  • 言語/フレームワーク: Vanilla TypeScript（フレームワーク非依存）+ Vite
  • 描画: Canvas 2D API
  • 音声: Web Audio API による波形合成の効果音（外部音源ファイル・課金APIは不使用）
  • 永続化: localStorage のみ（効果音ON/OFF設定等）
  • 外部通信: なし（完全にブラウザ内で完結）
