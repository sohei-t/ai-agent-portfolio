はじめに

このゲームについて

3-Adventure — Voidmaw Descent は、three.js + TypeScript製の3Dローポリ・サバイバルアクションです（Vampire Survivors型）。見捨てられた荒野に「ヴォイド」の裂け目が生まれ、住人はホロウと化していく——プレイヤーは荒野の生存者として、裂け目の中枢の怪物 Voidmaw の撃破を目指します。

🎯 目的

10分1ランのサバイバル。ボスを倒すか、力尽きるまで戦い抜く

✨ 特長

キャラクター・武器はマニフェスト（JSON）駆動。Meshy + Blenderの自動パイプラインで追加・削除できる
📖 このサイトは仕様書と操作手順書の二部構成です。左メニューでページを開くと音声解説が自動再生されます。

世界観と1ランの流れ

見捨てられた荒野に「ヴォイド」と呼ばれる裂け目が生じ、住人たちは徐々に浸食され、敵性生物「ホロウ」と化していく。プレイヤーは荒野の生存者として、裂け目の中枢に巣食う怪物 Voidmaw（ヴォイドモウ） の撃破を目指す。既存IPを参照しないオリジナルの、ポストアポカリプス×ウェスタン世界。

武器とパッシブ

近接・遠隔・範囲の各カテゴリを揃えた8種の武器。Lv8到達＋対応パッシブの所持で、専用の進化形態へ自動アップグレードします。

  • 刃こぼれの大鉈（近接）→ 処刑人の刃に進化
  • 投げ斧（近接）
  • 錆びたリボルバー（遠隔）→ 無双の平定者に進化
  • 静電コイル銃（遠隔）→ 嵐呼びの陣に進化
  • 燃え杭の杖（範囲）→ 大災禍の残り火に進化
  • 荊棘の輪（範囲）
  • 天穿ちの砲台（拡張・遠隔）
  • 守護のパルス（拡張・範囲）
拡張武器2種（天穿ちの砲台・守護のパルス）はショップで解放しないと抽選プールに出現しません。

パッシブは6種：砥石のかけら（ダメージ+8%/stack）、早撃ちの弾帯（CD短縮）、不安定核（AOE範囲拡大）、導電コイル（貫通/連鎖+1体）、鋼の心臓（HP+15）、迅速の靴（移動速度+6%）。いずれも複数スタック可能です。

技術アーキテクチャ

キャラクター・武器・パッシブは characters.json / weapons.json / passives.json のマニフェストで定義され、TypeScriptコードにはハードコードされていません。

コンセプト設計 → Meshy API（Text-to-3D） → Blender（自動リギング） → マニフェスト登録

大量湧きの敵（シャンブラー・スキッタリング）は Structure-of-Arrays プーリング＋InstancedMeshの2段階LODで描画し、個体差の見た目が重要な敵（ブルート・スピッター・エリート・ウォーデン・ボス）とプレイヤーはGLB骨格アニメーション対応の個別プールで描画します。GLBモデル未生成のエンティティは procedural fallback（手続き型ジオメトリ）で描画されるため、パイプラインが完了していない段階でもゲームは正しく動作します。

操作手順書

はじめの一歩

  1. launch_app.command をダブルクリックしてローカルサーバーを起動（またはGitHub Pagesで公開URLを開く）
  2. タイトル画面から「Start」を選択
  3. キャラクター選択画面でプレイするキャラクターを選ぶ
  4. ラン開始。10分間サバイバルする
初回プレイはレルがおすすめです。バランス型で最も扱いやすいキャラクターです。

操作方法（スマホ / PC）

📱 スマホ

画面右下のバーチャルスティックで移動。攻撃・武器発動はすべて自動です。縦・横どちらの向きでもプレイ可能

🖥 PC

WASD / 矢印キーで移動。攻撃は自動、レベルアップ時に武器・パッシブの選択肢が表示されます
攻撃ボタンはありません——狙いも発射もすべて自動なので、移動と立ち回りに集中できます。

攻略のコツ（ビルド戦略）

  • レベルアップ時は、手持ちの武器と噛み合うパッシブを優先する（例: 貫通/連鎖武器 + 導電コイル）
  • Lv8＋対応パッシブで進化が発生する武器を序盤から意識して選ぶ
  • Hordeイベント（3:00/6:00/9:00）の直前は安全な位置取りを確保しておく
  • ゴールドは死亡しても持ち越されるため、無理せず経験を積んでメタ進行を強化するのも有効
操作手順書

キャラ・武器の追加/削除（アセットスタジオ）

tools/asset-studio が、Meshy APIとBlenderを自動でつなぐパイプラインです。新しいキャラクターや武器は、以下の流れで追加できます。

  1. 見た目のコンセプトを英語プロンプトで設計する
  2. Meshy APIでtext-to-3Dモデルを生成する
  3. Blenderの自動処理でリギング・エクスポートを行う
  4. 生成物を characters.json / weapons.json に登録する
コード変更・再デプロイは不要です。マニフェストに登録するだけで、次回の読み込みからゲームに反映されます。削除も、マニフェストからエントリを取り除くだけです。

よくある質問（FAQ）

Q. 画面が真っ暗/動かない
A. WebGL対応ブラウザ（最新のChrome/Safari/Edge）で開いているか確認してください。

Q. スマホで操作がしにくい
A. 画面右下のバーチャルスティックのみで移動できます。攻撃は自動なので、指を動かす操作は移動だけです。

Q. セーブデータは保存される？
A. ゴールドやアンロック状況はブラウザのLocalStorageに保存されます。別のブラウザ・別端末では引き継がれません。

Q. キャラクターや武器のモデルが簡素な見た目に見える
A. GLBモデル未生成のエンティティは procedural fallback（手続き型ジオメトリ）で描画されています。アセットスタジオでモデルを生成すると自動的にアップグレードされます。
