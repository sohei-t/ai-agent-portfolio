# 3-Adventure — Voidmaw Descent

3Dローポリキャラクターで遊ぶブラウザ完結のサバイバルアクション（Vampire Survivors型）。three.js + TypeScript製、スマートフォン対応。

見捨てられた荒野に「ヴォイド」と呼ばれる裂け目が生じ、住人たちは徐々に浸食され敵性生物「ホロウ」と化していく。プレイヤーは荒野の生存者として、裂け目の中枢に巣食う怪物 **Voidmaw（ヴォイドモウ）** の撃破を目指す、オリジナル設定のポストアポカリプス×ウェスタン世界。

詳しい解説（世界観・遊び方・技術的な見どころ）は [about.html](./about.html) をご覧ください（日英切り替え・音声解説つき）。仕様書・操作手順の全文は [docs/](./docs/index.html) にあります。

## 遊び方

1回のプレイは10分間。ボスを撃破すればクリア、HPが0になれば死亡——どちらの結末でも、獲得したゴールドは永続的に保存され、次のランをより有利にする。

| プラットフォーム | 移動 | 攻撃 |
|---|---|---|
| スマートフォン | 画面右下のバーチャルスティック | 自動発動（ボタン操作不要） |
| PC | WASD / 矢印キー | 自動発動、レベルアップ時に武器・パッシブを選択 |

- 画面の縦向き・横向きどちらでもプレイ可能
- インストール不要、ブラウザだけで完結

## 特徴

- **プレイアブルキャラクター3体**: バランス型のRell、タフな近接特化のBrynn、俊敏だが打たれ弱いglass cannonのWisp。ゴールドで解放可能。
- **武器8種＋進化4種**: 近接2・遠隔2・範囲2の必須6種＋拡張2種。Lv8到達＋対応パッシブ所持で専用の進化形態へ自動アップグレード。
- **パッシブアイテム6種**: ダメージ・クールダウン・範囲・貫通/連鎖・最大HP・移動速度をスタック強化。
- **敵5種＋ボス1体**: 8分時点で最大139体が同時出現（プール上限150体）。3:00/6:00/9:00にHordeイベント、10:00にボスVoidmaw出現。
- **メタ進行**: ラン結果に関わらずゴールドを永続保存（LocalStorage）。最大HP・移動速度・XP/ゴールド獲得量・開始レベル・1ラン1回の死亡無効化などをショップで強化。
- **マニフェスト駆動のアセット管理（最大の技術的特徴）**: キャラクター・武器は `project/public/assets/{characters,weapons,passives}.json` で定義され、TypeScriptコードにはハードコードされていない。`tools/asset-studio` が Meshy API（text-to-3D）とBlender（自動リギング・エクスポート）を自動でつなぐパイプラインとして機能し、新しいキャラクターや武器を**コード変更・再デプロイなしで**追加・削除できる。GLBモデルが未生成のエンティティは procedural fallback（手続き型ジオメトリ）で描画されるため、パイプラインが完了していない段階でもゲームは正しく動作する。

## 技術スタック

- **エンジン**: three.js（WebGL）、TypeScript、Vite
- **レンダリング最適化**: Structure-of-Arrays（SoA）プーリング＋InstancedMeshの2段階LODを、大量湧きの敵タイプ（shambler/skitterling）に適用。個体差の見た目が重要な低頻度の敵（brute/spitter/elite_warden/boss）とプレイヤーはGLB骨格アニメーション対応の個別プールで描画
- **テスト**: Vitest（ユニット・統合）、Playwright（E2E）
- **アセット**: Meshy API（3Dモデル生成）、Blender（自動リギング・エクスポート）、GLTF/DRACO圧縮

## 既知の制約

- ~~E2Eテストの実行はこの開発環境では未実施~~ → **解消済み（2026-07-07）**: 実ブラウザ（Chrome）で全63シナリオ合格。初回実行により実バグ1件（キーボード操作後にタッチでジョイスティックが復帰不能になる問題）を発見・修正し、回帰テストを追加した。
- **GLBモデルは未同梱**: 全キャラクター・敵は現時点で procedural fallback（手続き型ジオメトリ）で描画される。Meshy + Blenderパイプラインで実際のキャラクターモデルを生成すれば、`public/assets/models/` に配置するだけで自動的に見た目がアップグレードされる（コード変更不要）。
- **武器モデルはプリミティブ形状**: 現状の武器グリップは簡易的なプリミティブ形状で代替している。この開発環境ではBlender自動処理を伴う武器モデルの本生成は行っていない（アセットパイプライン自体は`tools/asset-studio`として実装済み）。
- **BGM未実装**: 効果音（15種）は procedural synthesis + MP3圧縮で実装済みだが、BGMループは別途作曲が必要なため未実装。効果音のみでゲームは正常に動作する。
- **拡張武器2種の簡略実装**: `sky_lance_turret` と `guardian_aegis_pulse`（ショップ解放後のみ出現するMEDIUM優先度武器）は、既存の発射ロジックを流用した実装になっている（ダメージ/クールダウンの数値はSPEC.md通り）。
